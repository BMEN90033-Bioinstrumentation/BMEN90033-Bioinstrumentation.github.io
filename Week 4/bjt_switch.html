The BJT as a switch

A bipolar junction transistor driven between cutoff and saturation operates as a current-controlled switch. A small base current determines whether the collector-emitter path conducts, so a low-power control signal can switch a load such as an LED, relay or solenoid supplied from a separate rail. This page develops the operating regions, the base-drive condition for saturation, and the power dissipated in the device.

01the switching circuit

Low-side and high-side transistor switches

In the NPN low-side switch the load $R_L$ connects the supply $V_{CC}$ to the collector, the emitter is grounded, and the control voltage $v_\text{in}$ drives the base through $R_B$. The PNP high-side switch places the emitter at $V_{CC}$ and the load between collector and ground, so the transistor conducts when its base is pulled below the supply.

The base-emitter junction is a forward-biased diode once it conducts, so the base loop fixes the base current:

$$I_B = \begin{cases} \dfrac{v_\text{in} - V_{BE(\text{on})}}{R_B}, & v_\text{in} \ge V_{BE(\text{on})} \\[6pt] 0, & v_\text{in} < V_{BE(\text{on})} \end{cases} \qquad I_E = I_C + I_B$$

For the PNP switch the drive term is $V_{CC} - v_\text{in}$ and the junction voltage is $V_{EB(\text{on})}$. The model uses silicon values typical of the 2N3904 and 2N3906:

  • $V_{BE(\text{on})} = 0.7\,\text{V}$, the junction voltage once the base conducts;
  • $V_{CE(\text{sat})} = 0.2\,\text{V}$, the residual collector-emitter voltage when saturated;
  • $h_{FE}$, the forward current gain in the active region, set independently below.
$R_B$ limits the base current. Without it the base-emitter junction would be a diode connected directly across the drive source, and the base current would be limited only by the source impedance.

02regions of operation

The output characteristic and the load line

Kirchhoff's voltage law around the collector loop constrains the collector current and voltage to a straight line, the DC load line:

$$I_C = \frac{V_{CC} - V_{CE}}{R_L}$$

The load line runs from $V_{CE} = V_{CC}$ at $I_C = 0$ to $I_C = V_{CC}/R_L$ at $V_{CE} = 0$. The operating point is its intersection with the transistor characteristic for the present base current. Three regions result:

  • cutoff: $v_\text{in} < V_{BE(\text{on})}$, so $I_B = I_C = 0$ and $V_{CE} = V_{CC}$. The switch is open.
  • forward active: $I_C = h_{FE} I_B$ and $V_{CE(\text{sat})} < V_{CE} < V_{CC}$. The transistor behaves as a current-controlled current source.
  • saturation: $h_{FE} I_B$ exceeds the current the load permits, so $V_{CE} = V_{CE(\text{sat})}$ and $I_C = I_{C(\text{sat})}$. The switch is closed.
$$I_{C(\text{sat})} = \frac{V_{CC} - V_{CE(\text{sat})}}{R_L}$$
In saturation the collector current is set by $V_{CC}$ and $R_L$, not by $h_{FE}$. A switch is intended to rest in cutoff or saturation and to cross the active region only during transitions.

03base drive

The condition for saturation

The transistor saturates once the base current exceeds the value needed to sustain $I_{C(\text{sat})}$ in the active region:

$$I_B \ge \frac{I_{C(\text{sat})}}{h_{FE}} \quad\Longrightarrow\quad R_B \le \frac{\left(v_\text{in} - V_{BE(\text{on})}\right) h_{FE}}{I_{C(\text{sat})}}$$

Equivalently, the input voltage at the edge of saturation is

$$v_\text{in,sat} = V_{BE(\text{on})} + \frac{R_B\, I_{C(\text{sat})}}{h_{FE}}$$

Between $V_{BE(\text{on})}$ and $v_\text{in,sat}$ the collector current rises linearly with the input and $V_{CE}$ falls from $V_{CC}$ towards $V_{CE(\text{sat})}$. This is the transfer characteristic of a single-transistor inverter.

$h_{FE}$ varies by a factor of three or more between devices of the same type and also changes with temperature and collector current. A switch is therefore designed with the minimum datasheet gain and a margin of overdrive. In saturation the ratio of collector to base current falls below $h_{FE}$; this ratio is the forced beta,

$$\beta_\text{forced} = \frac{I_{C(\text{sat})}}{I_B} < h_{FE},$$

for which a value near 10 is a common design target.

Reducing $R_B$ or raising $h_{FE}$ moves $v_\text{in,sat}$ towards $V_{BE(\text{on})}$ and sharpens the transition. Increasing the load current through $V_{CC}$ or $R_L$ moves it to higher input voltages.

04time-domain switching

Response to a periodic drive signal

With a square-wave drive of sufficient amplitude the transistor alternates between cutoff and saturation, and the collector current is a square wave of height $I_{C(\text{sat})}$, independent of $h_{FE}$.

A sinusoidal or ramp drive passes through the active region on every cycle. While it does, $i_C$ follows $h_{FE}\, i_B$ and the output is a distorted copy of the input rather than a clean logic level. The emitter current is the sum of the other two, $i_E = i_C + i_B$, and lies just above $i_C$ because $i_B$ is small.

The model is quasi-static: each instant is solved as a DC operating point. A real BJT adds a turn-on delay set by the junction capacitances and a storage time on leaving saturation, while the excess base charge is removed. For a 2N3904 the storage time is of the order of 200 ns, which limits the switching frequency of heavily saturated designs.

The average dissipation reported beside the plot is lowest for the square wave, because the device spends almost no time in the active region.

05dissipation

Power dissipation and junction temperature

The power dissipated in the transistor is

$$P_D = V_{CE}\, I_C + V_{BE}\, I_B$$

In cutoff $I_C = 0$, and in saturation $V_{CE}$ is only $V_{CE(\text{sat})}$, so both switch states dissipate little. Along the load line the collector term is $(V_{CC} - I_C R_L)\, I_C$, which is largest at $I_C = V_{CC}/2R_L$, the midpoint of the active region:

$$P_{D,\max} \approx \frac{V_{CC}^2}{4 R_L}$$

The junction temperature follows from the thermal resistance between junction and ambient:

$$T_j = T_A + R_{\theta JA}\, P_D$$

with $R_{\theta JA} \approx 200\,{}^\circ\text{C/W}$ for a TO-92 package and $T_A = 25\,{}^\circ\text{C}$. The 2N3904 is rated to a maximum junction temperature of $150\,{}^\circ\text{C}$, which corresponds to about 625 mW in this package.

A transistor that is not driven fully into saturation can overheat at a load current it would switch safely when saturated. Raising $R_B$ until the operating point enters the active region shows the dissipation rise towards the peak.
