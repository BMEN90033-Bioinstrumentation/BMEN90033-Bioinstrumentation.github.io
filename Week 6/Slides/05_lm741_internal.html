Internal circuitry of the LM741 op-amp
  • Detailed transistor-level analysis is outside the scope of this topic
  • The labelled regions identify the principal functional blocks
  • The complete schematic provides context for the simplified op-amp model
Differential inverting stage Q1–Q7 · lateral PNP input pair Amplifies the voltage difference between the two inputs and rejects the common-mode signal. This stage sets the high input impedance and low input bias current of the op-amp.
Current mirrors Q8/Q9 · Q10/Q11 · Q12/Q13 The internal bias network copies one reference current to every stage. Each transistor receives a stable operating point, and the mirrors act as high-impedance active loads that maximise gain.
Class A gain stage Q15, Q19, Q22 A high-gain common-emitter stage, biased in class A with an active load. Together with the input stage, it provides the open-loop voltage gain of about 100 dB. The 30 pF Miller capacitor sets the dominant pole for stability.
Voltage level shifter Q16 with 4.5 kΩ and 7.5 kΩ (VBE multiplier) A VBE multiplier holds a fixed DC offset between the bases of the two output transistors. Both transistors are biased slightly into conduction, which avoids class-B crossover distortion.
Output stage Q14, Q17, Q20 · class-AB push-pull A complementary push-pull pair sources or sinks load current at the output pin and gives the op-amp a low output impedance. On ±15 V supplies the output swings to about ±13 V, so the output is not rail-to-rail.
